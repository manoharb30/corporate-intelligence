# Signal Journal

A running notebook for **learning every day** from the signals we ship. Two lines per
signal: one at **formation** (thesis + biggest risk/horizon read) and one at
**maturation** (outcome vs that read + the lesson, if any). This is a notebook, **not a
gate** — it sharpens how we read and talk about signals; it never removes one the
mechanical gates passed.

- **Cadence:** after each scan/backfill, note interesting tickers here. When a signal
  matures, close its loop with the outcome + lesson.
- **Lesson graduation:** when the same observation recurs across enough maturations it
  becomes a **risk flag** we check at every new arrival (a lens, never a filter).
- Cohort is FROZEN once matured — we study it, never reclassify it.

## Confirmed lessons (from the frozen 192-signal cohort, mined 2026-07-09)

Overall cohort baseline: **HR 65.6%, avg return +13.7%, avg alpha +7.5pp.** Segmenting
the matured signals by their day-0 tells surfaced five patterns that separate winners
from losers:

**L1 — Cluster dollar size is NOT conviction. The $1M–$5M band is a dead zone.**
- val < $250K → **HR 73.7%, alpha +14.0** · $250K–$1M → HR 64%, +6.4 · **$1M–$5M → HR 51.4%, alpha −2.7** · ≥$5M (n=11) → HR 81.8%, +14.8
- A big-dollar cluster does not mean a better signal. Mid-size clusters ($1–5M)
  underperformed SPY. The worst losers were big-dollar (NFE $2.7M −62%, CLVT $7.7M −48%).
- **Flag at arrival:** don't be impressed by headline cluster $. A $1–5M cluster is a
  yellow light, not a green one.

**L2 — Alpha concentrates in $500M–$1B mcap; mega-caps (≥$2B) barely beat SPY.**
- <$500M → HR 65%, alpha +11.6 · **$500M–$1B → HR 75.9%, alpha +12.7** · $1–2B → +5.5 · **≥$2B → HR 56.5%, alpha −0.5**
- The $300M floor protects the downside; the real edge lives in small-to-mid caps. A
  ≥$2B name needs more than the cluster to be interesting.

**L3 — Biotech is bimodal, high-variance. Keep it; size expectations wide.**
- biotech n=26 → **avg return +24.5%, alpha +18.2** (same 65% HR as non-bio, but far
  fatter tails). Right tail: ABSI +191%, TLRY +134%, NUVB +83%. Left tail: DNA −66%,
  AARD −63%, RCKT −48%.
- Confirms the never-filter-biotech policy — the moonshots pay for the busts. But never
  over-size confidence on any single biotech; treat each as a wide-distribution bet.

**L4 — More insiders ≠ better. Insider count is a gate, not a linear score.**
- 2 insiders → alpha +8.2 · **3 → alpha +3.0, beatSPY only 51.4%** · 4+ → alpha +9.2
- The 3-insider tier was oddly the weakest. Don't upweight a signal just because it has
  more buyers past the 2-buyer bar.

**L5 — The left tail is distressed / serial-diluter names.**
- Bottom of the cohort: NFE (natural-gas distribution, leverage) −62%, DNA (Ginkgo,
  serial diluter) −66%, CLVT −48%, RPD −59%, STEX −50%.
- Confirms the **capital-action-after-signal / high-leverage red flag** first
  hypothesized 2026-06-18 (ALT, BETR, VTS) — now visible across the matured cohort.
- **Flag at arrival:** high debt load, recent/likely equity raise, or dividend risk =
  the recurring drawdown driver. Check for it; don't gate on it.

> Note: signal_level (high vs medium) barely separated outcomes (alpha +7.2 vs +7.7) —
> low information beyond the insider-count/value/mcap tells above.
